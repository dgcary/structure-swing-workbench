# Structure Swing Workbench

个人 A 股短线波段研究、交易计划与纪律审计工作台。

## 目标

形成一条完整但不自动下单的工作流：

**AI 按既定体系筛候选 → TradingAgents / StockResearchPack 研究 → 用户判断趋势与结构 → 创建交易计划 → 纪律审计 → 手工执行 / 导入成交 → 持仓管理 → 复盘**

系统的核心不是预测市场，而是把已经确定的交易体系变成可审计、可追踪、可复盘的执行系统。

## 核心边界

- AI 负责按既定规则缩小候选范围并做风险筛查。
- 用户负责趋势、结构、关键位、Setup、反转确认和最终买卖决定。
- 程序负责纪律检查、风险计算、成本计算、版本记录和复盘。
- 第一阶段不做自动交易。
- 任何 AI 研究结论都不能绕过纪律审计。

## 交易体系

**Structure Swing v1｜结构型短线波段体系 + Intraday T Overlay**

Setup 优先级：

1. C：上升趋势早中段回踩（主要方向）
2. A：箱体下沿
3. B：前期上涨后约 65%～75% 深回撤，并要求结构支撑共振

详见 [docs/trading-rules.md](docs/trading-rules.md)。

## 技术原则

- Ubuntu + Docker 部署。
- 单用户优先，不做多租户 SaaS。
- 模块化拼装，优先复用成熟开源项目。
- 行情、账户、研究系统通过适配器接入。
- 自研重点仅放在交易计划、动作、审计规则、版本管理、T 仓和复盘。
- 所有用户可见业务术语使用中文。
