# M5｜账户 CSV 输入协议（初版）

此模块只记录客观账户事实，不发出交易指令。所有金额/数量为十进制，时间为带时区 ISO8601。

- `account`：列 `equity,available_cash,as_of`，每批恰好一行。
- `holdings`：列 `symbol,quantity,cost,as_of`，每批证券代码不得重复。
- `fills`：列 `fill_id,symbol,side,quantity,price,executed_at`；方向为 BUY/SELL。
- 调用 `import_csv(ledger, kind, text, batch_id=...)`；相同批次相同字节幂等，不同内容拒绝。
- 每个成交编号不可变；跨批重复相同成交去重，不同成交内容冲突并拒绝。
- 来源优先级：确认成交 > 同步快照 > 人工修正 > 计划。
- 持仓数量使用最新基准快照加上基准时间后确认成交的净数量；无基准快照时数量未知。
- 没有券商费用/成本结转口径时，不从成交价格推断当前券商显示成本。
- 事实替换和冲突保留审计记录；整批导入先在副本校验，再原子提交。

第一版为内存领域适配，持久化、券商特定列名映射及 Web 接口属于后续集成，不应假定自动完成。
