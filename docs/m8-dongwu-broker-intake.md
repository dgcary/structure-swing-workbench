# M8 东吴证券数据接入取证清单

状态：**待真实样例**。使用的客户端已确认为东吴秀财手机 App。此文档用于准备只读对账，不代表券商接入、账户认证或交易许可。

## 已核实的公开信息

- [东吴证券证券经纪官网](https://www.dwzq.com.cn/main/services/wealth/securitiesEconom/index.html)将“对账单”列为东吴秀财的账户管理服务。
- [东吴证券官方下载中心](https://www.dwzq.com.cn/main/online/download/index.html)列有东吴秀财手机 App 和电脑金融终端。应以官网提供的客户端为准。
- 官网公开页面没有给出东吴秀财对账单的精确导出路径、可导出文件类型、列名、逐笔成交编号、历史查询范围或全天覆盖水位。因此当前**不得编造东吴专用字段映射**，也不得把 App 截图或自报清单认作全量成交证明。

## 待取得的最小材料

从同一个东吴账户、同一个导出批次取得以下材料，并记录 App 版本、导出时间（含时区）、查询起止日期和文件类型：

1. 账户权益与可用资金快照，保留原始字段名和来源时间。
2. 全部持仓快照，保留证券代码、数量、成本、可卖数量及来源时间（若原文件有这些列）。
3. 覆盖测试日期的成交明细或交割单，保留每笔证券、买卖方向、数量、成交价、成交时间、成交编号或可复核的组合键（以原文件实际字段为准）。
4. 能表明查询范围及逐日完整性的导出页、页眉或对账单说明；若 App 不提供完整性水位，应如实记录“未知”。

脱敏时将真实姓名、手机号、证件号和资金账号替换为各文件一致的假值；保持列名、日期范围、交易顺序、数量、价格和同一成交的关联关系。不要提供登录密码、短信验证码或交易授权。原始材料仅用于本地隔离核对，不提交到 GitHub。

## 接入顺序与验收边界

1. 先识别实际文件类型和字段；为该格式编写只读解析器及脱敏固定样例测试。无法唯一识别账户或逐笔成交时返回待核验，不推断缺失字段。
2. 对同一账户、每个交易日分别核对导出范围、成交编号及逐笔内容，报告缺失、额外、重复、跨日期和水位外记录。无成交日须有独立的覆盖证据，不能从空文件推断零成交。
3. 将脱敏样例导入隔离 PostgreSQL 后与解析结果逐笔对照；仅在账户身份、来源和完整性均独立核实后，才能讨论 T+1、日终 BROKEN T 正式转仓与当前风险指标。
4. 在上述证据齐备之前，`broker_reconciled=false`、`full_account_verified=false`、`trade_execution_enabled=false`，M8 Gate 保持 FAIL，PR #19 保持 Draft。

若东吴秀财只提供 PDF、图片或页面查看，应先保留原始导出证据和覆盖范围，不把人工转录结果称为券商认证 CSV。需要时可联系东吴证券官网列示的官方客服确认可取得的格式与日期范围。
